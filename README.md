# Sheap Calculator

حاسبة ربح الأغنام — مشروع Static Frontend فقط.

## التشغيل
لا يحتاج المشروع إلى Backend أو قاعدة بيانات أو API. افتح `index.html` مباشرة في المتصفح.

## Render
- Service Type: Static Site
- Branch: main
- Build Command: `echo "No build required"`
- Publish Directory: `./`

الواجهة عربية RTL وتعمل بالكامل داخل المتصفح.


## Cloudflare

This project is configured for Cloudflare Workers Static Assets using `public/` as the asset directory.
